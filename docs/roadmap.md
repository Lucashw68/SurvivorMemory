# Roadmap

## MVP

Mémoire bâtiment, visites, rooms, containers, statuts, panneau NeatUI avec
fallback vanilla, persistance réelle par personnage et sanity MP.

## MVP+1

Overlay World Map non destructif et désactivable: livré. Les filtres
d'affichage avancés restent optionnels.

## MVP+2

Item Memory / « Where Did I Put It? », recherche dans les souvenirs et
éventuellement confiance liée à l'âge.

## Plus tard

Souvenirs véhicules, partage explicite, notebooks/cartes et oubli configurable.
